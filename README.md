# 做一点｜收藏夹落地器

在线作品：[REDcowork 正式版](https://redcowork.xiaohongshu.com/f/g7rcew51y4)

`redcowork.html` 是平台导入入口：内嵌脚本和样式，媒体使用固定 Git 提交的远程地址；本地完整版见 `standalone.html` 和 `assets/`。

当前版本：`v0.2.0`（2026-10-14）。日常七日计划、埃及旅行专辑、来源交叉汇总、共同专辑演示与 Excel 导出。

![电脑端预览](desktop-preview.png)

把小红书里想尝试的事安排进空闲时间。美妆、发型、做饭、手作、运动、穿搭、家居、园艺等活动都可以添加。电脑端左右各半，收藏区采用较小的三列封面；手机自动切换为单栏。纯 HTML、CSS、JavaScript，无后端。

## 打开与使用

浏览器打开 `index.html` 或 `standalone.html` 即可运行，或在本目录运行 `python -m http.server 8765` 后访问 `http://127.0.0.1:8765/`。`standalone.html` 合并脚本、样式和图片；视频按需从同目录的 `assets/` 加载，请保留该文件夹。

1. 添加想做的事，填写标题和实践耗时。可以贴入小红书分享文案，提取标题与原帖链接。
2. 按需填写准备材料、可开始状态、时间窗口和前置事项。只有出门活动才显示地点、户外与预约选项。
3. 选择日期与当天空闲时段，点击「安排一下」，完成后打勾或导出 Excel 计划。

在家事项不需要地址或营业时间。未准备好的事项暂缓；前置事项先于后续事项完成；出门与回家预留通勤，同一地点不重复计通勤。删除后可在提示中撤销。

## 真实笔记与演示设定

内置十一条公开小红书笔记，已在 2026-10-14 打开原帖核对标题与作者：淡妆、低盘发、番茄浓汤面、A4 纸收纳盒、普拉提、穿搭、收纳、绣球，以及新增的下山虎火锅、11:11 Store、一坐一忘云南菜。原有来源记录在 `source-notes.json`，新增探店来源在 `outing-sources.json`。收藏区展示原帖封面、标题和作者头像；图片保存在 `assets/`。

点击封面在左侧查看详情，四条视频示例使用原帖提供的媒体资源，在本地播放；关闭详情会停止播放，右侧计划保留。视频来源见 `video-sources.json`。新粘贴的任意小红书链接不会自动解析或下载视频，原帖入口保留在详情顶部。

支持搜索、分类筛选和封面左上角勾选；每条收藏的「…」菜单可编辑安排、设置优先级或删除。材料、安排设置与未排入的原因均折叠显示。

示例分类经过手动确认。新增收藏时，`categories.js` 根据标题关键词建议分类；用户手动选择后不再自动覆盖。没有标题或未命中关键词时归入「其他」。这不是 AI 内容识别，也不是小红书自动同步的分类。详情内也可手动修改分类。

新增示例只在旧数据升级时补入一次，保持原有选择与计划；之后删除不会反复恢复。

行动名称、实践耗时、准备清单、午饭时间窗口以及先做发型再化妆的顺序是可编辑的演示设定，不是自动抓取结果。原帖在小红书网页上可能需要登录才能查看。网页中的原帖链接保留平台生成的访问参数。

所有录入与完成状态保存在当前浏览器 localStorage；没有登录同步或自动读取收藏夹。

## 代码与验证

## 旅行专辑原型（早期版本）

已登录并检查用户收藏专辑，网页端未显示用户提及的澳新专辑，经用户选择后使用「埃及」。原专辑显示 21 篇，本地选取并阅读其中 9 篇旅行攻略，手动整理主线 13 个地点。来源标题、作者、原帖链接、封面、头像与整理注释见 travel-sources.json；不含账户资料或其他无关收藏。

点击「旅行专辑」查看原封面与标题，切换「想去」勾选地点，「行前参考」保留交通、物品、季节穿搭等资料。相同城市和同名地点自动合并，并保留多篇来源。点击来源在左侧查看整理和原帖入口，右侧行程保留。

默认展示一份可编辑的 10 天草案，不代表用户真实出行日期。规则按城市首次出现顺序分组、控制每天地点数量；标记整天的事项独占一天；不足以排下的地点保留在待安排区。可改天、上移、暂不安排、加一天、重新生成后撤销及导出文字。修改设置需要点击重新安排，日期可即时调整。状态独立保存在 localStorage，不改动小红书收藏。

人工整理：地点、用途、建议整天与简短备注。自动处理：同城同名去重、保留来源、按城市与容量排天。别名需统一写法。尚无任意链接自动解析、收藏自动同步、真实距离计算、航班/开放时间/预约校验。作者的交通与票务经验不等于实时信息。跨城与人工制造的整天冲突会在草案提示。

番茄浓汤面核对为三张图文，补充完整图片与前后翻页、左右方向键切换；封面/详情显示图文类型。来源见 photo-sources.json。

验证：node --test planner.test.js travel-planner.test.js。浏览器隔离数据验证录入、去重、多来源、按城市分天、改天、暂不安排和刷新保存；真实专辑验证封面、来源预览、整天安排及页面对齐。

## 多日计划与出门收藏（v5 历史版本）

日常计划默认从今天起显示 3 天，也可切换 7 天。前一天、后一天和今天按钮只切换查看日期；每件事在一份七日计划中只排一次，当天放不下时顺延。已有用户保留上次选择的日期。重新安排会从当前查看日期生成七日计划；修改事项或时段会按原计划起点更新。每一天暂时共用同一个空闲时段。完成状态按日期保存，导出覆盖当前显示的日期范围。

时间改为紧凑的 15 分钟间隔下拉选项。旅行草案使用一致的日期、序号、地点与操作列，并增加出发日期前后一天切换。

餐厅和探店样例使用真实原帖封面与链接。耗时、通勤缓冲和午饭时段为可编辑设定；11:11 Store 的地址与营业时段来自原帖，未经实时核验；一坐一忘的具体门店保留为待确认。新样例不会自动选中或覆盖用户选择。

16 项排程测试通过，新增验证多日去重、跨日先后关系、周末限制、日期跨月跨年和首项出门通勤。浏览器隔离数据检查翻日不重排、跨日完成记录刷新后保留，以及旅行地点和操作列对齐。

## 演示版（v6）

移除多日统计说明与显示天数下拉框，恢复日期、当天时段和「安排一下」。下方连续显示三天；切换日期自动读取当天时段，修改时间或重新安排只改变当天。按用户要求一次性补入三天示例：妆发穿搭、咖啡与火锅、手作收纳与做饭。演示设定与实际完成状态分开，迁移前状态备份在本机 `zuoyidian-before-demo-v6`。原收藏、手动内容和完成记录保留。

旅行右侧改为城市分页，每天合并游览与用餐；攻略来源和移动日期、餐厅选择收进展开区。新增「吃什么」收藏筛选，从另外两篇公开小红书笔记人工整理 7 家餐厅，来源见 `travel-food-sources.json`。这两篇来自补充搜索，不属于原埃及专辑。自动匹配按城市进行，部分餐厅绑定具体游览地点，例如大埃及博物馆内的 Zooba 与西岸 Rustic House；没有匹配来源的日期不虚构餐厅。手动选择与暂不安排会保存，导出包含餐厅、菜品和来源。

餐次和分天为演示建议，非实时营业、预约或导航结果。餐厅位置缺失、跨城交通与跨岸安排在对应位置标明。19 项规则测试通过；浏览器隔离验证逐日修改不影响其他日期、餐厅调整保存、城市切换、原帖预览及导出。

22 项规则测试通过。浏览器验证日期时间对齐、选中图标居中、分类筛选、午晚餐显示、原帖依据、重新安排与撤销、刷新保存及文字导出。截图见 daily-v7-preview.png、travel-v7-preview.png。

## v10：共同专辑与 Excel 合并单元格

- 共同专辑：选择演示好友创建专辑，可切换身份调整安排，显示最近编辑者。同源浏览器标签页通过 storage 事件同步。

- 示例文件：日常计划示例.xlsx、埃及行程示例.xlsx。
- 验证：27 项 Node 测试通过；浏览器验证创建专辑、好友视角编辑、跨标签同步；openpyxl 读取两个导出文件并核对合并范围。
