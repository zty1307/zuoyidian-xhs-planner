# 做一点｜收藏夹落地器

存档版本：`v0.1.0`（2026-10-14）。小红书收藏视觉改版，包含当前可运行页面、源码、真实笔记图片与排程测试。

![电脑端预览](desktop-preview.png)

把小红书里想尝试的事安排进空闲时间。美妆、发型、做饭、手作、学习与出门活动都可以添加。电脑端双栏展示，手机自动切换为单栏。纯 HTML、CSS、JavaScript，无后端或外部运行依赖。

## 打开与使用

浏览器直接打开 `standalone.html` 即可运行，或在本目录运行 `python -m http.server 8765` 后访问 `http://127.0.0.1:8765/`。

1. 添加想做的事，填写标题和实践耗时。可以贴入小红书分享文案，提取标题与原帖链接。
2. 按需填写准备材料、可开始状态、时间窗口和前置事项。只有出门活动才显示地点、户外与预约选项。
3. 选择日期与空闲时段，点击「安排一下」，完成后打勾或导出文字计划。

在家事项不需要地址或营业时间。未准备好的事项暂缓；前置事项先于后续事项完成；出门与回家预留通勤，同一地点不重复计通勤。删除后可在提示中撤销。

## 真实笔记与演示设定

内置四条公开小红书笔记，已在 2026-10-14 打开原帖核对标题与作者：淡妆、低盘发、番茄浓汤面、A4 纸收纳盒。来源记录在 `source-notes.json`。收藏区展示原帖封面、标题和作者头像；图片来源记录在 `cover-sources.json`，图片保存在 `assets/`，单文件版内嵌这些图片，不依赖临时图片地址。视频标识表示来源笔记为视频，点击封面可前往原帖。

支持搜索、分类筛选和封面左上角勾选；每条收藏的「…」菜单可编辑安排、设置优先级或删除。材料、安排设置与未排入的原因均折叠显示。

行动名称、实践耗时、准备清单、午饭时间窗口以及先做发型再化妆的顺序是可编辑的演示设定，不是自动抓取结果。原帖在小红书网页上可能需要登录才能查看。网页中的原帖链接保留平台生成的访问参数。

所有录入与完成状态保存在当前浏览器 localStorage；没有登录同步或自动读取收藏夹。

## 代码与验证

- `index.html` / `style.css`：页面结构与电脑优先的响应式视觉
- `demo-notes.js`：四条真实笔记及可编辑的演示设定
- `planner.js`：准备状态、时间窗口、先后顺序和通勤约束下的组合排程
- `app.js`：录入、筛选、编辑、本机保存、完成记录、撤销删除与导出
- `planner.test.js`：关键排程约束测试，运行 `node --test planner.test.js`
- `build.js`：生成无外部依赖的单文件版本，运行 `node build.js`
